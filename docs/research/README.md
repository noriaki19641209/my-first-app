# 研究記録（docs/research）

AI家庭教師アプリの研究記録を保存します。教材の本文・図・解説は転載せず、研究結果（学習目標・つまずき・ヒントの考え方など）と出典・利用条件だけを記録します。

## ディレクトリ

| ディレクトリ | 内容 |
|---|---|
| `教育方針/` | 授業・声かけ・学習指導の考え方に関する研究（学習指導要領解説など） |
| `教材研究/` | 個別教材ごとの研究記録（1教材1ファイル） |
| `算数/` | 単元別の整理（複数教材の知見をまとめたもの） |

## 教材研究の記録方法

1. `教材研究/_テンプレート.md` をコピーし、`教材研究/<教材名>.md` として保存します。
2. 事実（出典で確認したこと）と推測を分けて書き、推測には「推測」と明記します。
3. 確認できない項目は「不明」とし、理由を書きます。
